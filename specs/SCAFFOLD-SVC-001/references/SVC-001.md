## C4  Summary

This C4 code-level diagram models the detailed architecture of the User Management API, focusing on core services handling user authentication and lifecycle management.

## C4  Insights

- The User Management API facilitates critical user functions such as registration, OTP verification, login, and account deletion using a robust microservice architecture.
- Emphasizes secure data practices by leveraging hashing and HTTPS protocols, and handles communication with external SMTP services for OTP delivery.
- Uses a clear service class structure separating concerns between controllers, services, and repositories for scalability and maintainability.

## C4  Methods

- **UserController.registerUser**  Handles user registration and calls UserService for business logic execution.
- **UserService.generateOTP**  Generates and manages OTP creation and validation processes.
- **UserRepository.findByEmail**  Fetch user details from the database using the email address.

## C4  Data structures

- User: Represents the user object with essential fields.
- OTP: Data structure for holding OTP codes and corresponding expiry times for verification.

## C4  Code relationships

- The UserController calls methods from UserService to perform business logic tasks.
- UserService uses UserRepository for any data persistence operations.

## API specification  Endpoints

### POST /api/v1/users
Register a new user and send OTP for verification.

### POST /api/v1/users/{userId}/otp/verify
Verify OTP entered by the user for account activation.

### POST /api/v1/auth/login
Authenticate user to generate session token after verifying credentials.

### DELETE /api/v1/users/{userId}
Delete a user account permanently, complying with GDPR regulations.

### GET /health
Perform health check of the User Management System.


## API specification  Summary

This API provides user registration with OTP verification, secure login, and GDPR-compliant account deletion. It ensures secure handling of credentials and user data, and enforces strict authentication and authorization policies.
